## Deployment Tool

The contract was deployed using Remix IDE with MetaMask connected to the Sepolia test network.

Sepolia ETH was used to pay the test-network transaction fee. No real ETH was required.

## Token Distribution

The constructor creates the initial supply of 100,000 KH42 and assigns all tokens to the deployer's address.

The contract does not include a public mint function.

## Verification Status

Remix reported successful contract verification through Routescan.

Etherscan source-code verification was attempted separately but was not completed during this deployment session.

## Important Note

KH42 is deployed on the Sepolia test network for educational and testing purposes. It is **not deployed on Ethereum Mainnet** and should not be treated as a real-money token.
